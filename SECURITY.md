# Security Policy

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Report it privately by email to:

**mattia.developing47@gmail.com**

Include:

- the affected page or component;
- clear reproduction steps;
- the expected and actual behavior;
- any relevant browser/device information;
- a proof of concept when appropriate.

Please avoid accessing data that is not yours, destructive testing, denial-of-service activity or automated scanning that could affect the live deployment.

## Scope

This repository is a static frontend portfolio. There is no application backend or database in the codebase.

Security-sensitive areas are therefore primarily:

- dependency and supply-chain issues;
- unsafe external links or browser behavior;
- client-side injection risks;
- accidental exposure of secrets or private project data;
- deployment configuration.
