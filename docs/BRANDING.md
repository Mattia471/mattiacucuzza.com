# Branding

The portfolio uses a deliberately compact visual identity built around a dark editorial interface and a single high-energy accent.

## Core palette

| Token | Value | Usage |
| --- | --- | --- |
| Surface | `#0a0a0a` | Main site background |
| Ink | `#f3f3ed` | Primary text and light logo |
| Lime | `#c8ff3d` | Accent, actions and highlights |

The lime accent should remain selective. It is meant to signal interaction or emphasis rather than become a general background color.

## Typography

- **Inter Tight** — primary interface and editorial typography
- **DM Mono** — metadata, labels, indexes and technical details

Both are loaded from Google Fonts in `index.html`.

## Logo assets

The canonical web assets live in `public/`:

- `logo-light.png` — light wordmark for dark surfaces
- `logo-dark.png` — dark wordmark for light/lime surfaces
- `favicon.png` — compact MC monogram

Use the existing transparent padding and proportions. Avoid stretching, recoloring or placing the logo on backgrounds that reduce contrast.

## Visual language

The current direction combines:

- oversized editorial type
- dark neutral surfaces
- thin borders and low-opacity metadata
- purposeful motion
- large project imagery/video
- restrained lime highlights
- asymmetrical desktop layouts that collapse cleanly on mobile

Motion should support hierarchy and orientation. It should never block navigation or make essential content dependent on animation.
